# 5 angles types pour générer les créatives

Quand on doit produire 5 à 10 créatives pour une campagne, on couvre obligatoirement les 5 angles suivants. Au-delà, on duplique l'angle gagnant en variations de format.

## Angle 1 — Douleur (Pain)

Verbalise une douleur précise du prospect dans les 3 premières secondes.
Format type : face cam, ton calme, regard caméra.
Hook type : *"Si t'es [persona] et que tu [galère précise], cette vidéo est pour toi."*
Body : on déroule la douleur, on montre qu'on la comprend, on dit pourquoi les solutions actuelles ne marchent pas.
CTA : direct, pas insistant.

## Angle 2 — Désir (Dream Outcome)

Met en avant la transformation finale.
Format type : face cam ou témoignage client.
Hook type : *"Voilà à quoi ressemble [résultat précis chiffré] quand on fait [méthode] correctement."*
Body : on peint la situation rêvée, on montre que c'est atteignable, on explique le mécanisme.
CTA : "Découvre comment [outcome]".

## Angle 3 — Preuve sociale (Social Proof)

S'appuie sur un cas client ou un résultat chiffré.
Format type : témoignage client en UGC ou case study face cam.
Hook type : *"[Prénom] a fait [résultat chiffré] en [délai] grâce à [méthode]."*
Body : on raconte l'histoire spécifique, contexte avant / pivot / résultat.
CTA : "Découvre la méthode utilisée".

## Angle 4 — Contre-intuitif (Pattern Interrupt)

Casse une croyance largement partagée du marché.
Format type : face cam, ton affirmé.
Hook type : *"Tout le monde te dit [croyance commune]. C'est faux. Voilà pourquoi."*
Body : on déconstruit la croyance, on amène le vrai mécanisme, on prouve.
CTA : "Voir la vraie méthode".

## Angle 5 — Urgence / scarcité (FOMO)

Crée une raison d'agir maintenant.
Format type : face cam ou static avec deadline.
Hook type : *"Plus que [X jours / X places] avant qu'on ferme [opportunité]."*
Body : on explique pourquoi la fenêtre est limitée, ce qu'on perd à attendre.
CTA : "Réserve ta place avant [deadline]".

## Format par défaut : images statiques

**Par défaut, les créatives dans la proposition de campagne sont des images statiques (1080x1080 ou 1080x1350).** On ne produit PAS de scripts vidéo sauf demande explicite de l'utilisateur.

Pour chaque créative statique, fournir :
- **Angle** (parmi les 5 ci-dessus)
- **Headline image** : la phrase courte affichée sur le visuel
- **Primary text** : le texte d'accompagnement Meta (angle + bénéfice + CTA)

Rester synthétique. Pas besoin de détailler un script complet pour du statique.

## Variations (créatives 6 à 10)

Une fois les 5 angles couverts, varier :
- Carrousel éducatif (5-7 slides)
- Variation de headline sur le même angle
- Variation visuelle (fond sombre vs fond clair)

## Structure d'un script vidéo (UNIQUEMENT si demandé par l'utilisateur)

Si l'utilisateur demande explicitement des scripts vidéo (face cam, UGC, etc.) :

```
HOOK (0-3s) : [phrase qui arrête le scroll]
BODY (3-25s) : [problème → mécanisme → bénéfice]
CTA (25-30s) : [action claire et unique]
```

Durée totale : 30s minimum (jamais en dessous), 45s standard, 60s maximum sauf VSL ad.
