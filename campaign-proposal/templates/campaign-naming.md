# Convention de nommage Meta Ads — the platform

## Campagnes
```
[CLIENT] - [OFFRE] - [OBJECTIF] - [YYYY-MM]
```
Exemples :
- `TopCo - Méthode 5DC - Leads - 2026-04`
- `BizCoach - Mentorat 1on1 - Conversions - 2026-04`

## Ad sets
```
[Nom court campagne] / [Type audience] - [Précision]
```
Exemples :
- `5DC / Intérêts - Closing FR`
- `5DC / Broad - France 25-45`

## Créatives
```
[Nom court campagne] / [Format] / [Angle] / V[n°]
```

Formats : `FaceCam` / `UGC` / `Static` / `Carousel` / `VSL`
Angles : `Douleur` / `Désir` / `Preuve` / `ContreIntuitif` / `Urgence`

Exemples :
- `5DC / FaceCam / Douleur / V01`
- `5DC / UGC / Preuve / V02`
- `5DC / Static / Désir / V03`

## Pourquoi cette convention
- Tri rapide dans le Business Manager
- Reporting clair par angle / format
- Identification immédiate du gagnant pour scaling
