# Iteration Go / No-Go Gate

À remplir **avant de déclencher** une version v_{N+1}. Évite les boucles de mauvaise qualité.

---

## ☐ 1. Council rendu (4 seats)

- [ ] Brand Guardian — verdict lu et synthétisé
- [ ] UX Researcher — prédiction CPL lue
- [ ] UI Designer — verdict esthétique lu
- [ ] Copywriter — nombre de hooks à réécrire compté

**Si un seat manque → NO GO**. Relancer l'agent absent.

---

## ☐ 2. Consensus Council

Sur les 4 verdicts, au moins **3 axes convergents** identifiés :

Exemple Acme v2 :
- Brand 8.5, UX CPL 380-430€, UI plus belle = **Angle 2 Anti-360° winner**
- Brand < 7, UX CPL 550-650€, UI contraste 3.1:1 = **Angle 3 Transparence loser**

Si Council partagé (pas de winner/loser clair) → reconsidérer ou demander audit humain.

---

## ☐ 3. Hypothèse v{N+1} explicite

Sur 1 page, rédiger `_strategy.md` avec :

- **Ce qui change** vs v{N}
- **Pourquoi** (citations verbatim des verdicts Council)
- **Nouveaux angles** qui attaquent les white spaces
- **Angles retirés** et pourquoi

---

## ☐ 4. Copy repassé par la checklist 6 points

Pour chaque nouveau hook / sub / body / CTA de v{N+1} :
- [ ] AGENCY check
- [ ] AWARENESS stage unique
- [ ] PAIN-hook vs DESIRE-body
- [ ] SPECIFICITY chiffrée
- [ ] SOURCE vérifiée
- [ ] VOIX de la cantine

Voir `checklists/copy-validation-6-points.md`.

---

## ☐ 5. Budget fal.ai estimé

- v{N+1} aura **combien** de créatives avec background fal.ai ?
- À $0.003/image × 4 steps × nombre créatives = budget estimé
- Si > 5 USD par itération → limiter ou cacher plus agressivement

---

## ☐ 6. Format diversification

v{N+1} doit introduire au moins **1 nouveau format / layout** si possible :

- [ ] Hero Number Big (déjà utilisé ?)
- [ ] Hook Italique 3-lines
- [ ] Timeline Horizontal
- [ ] Diptych Before/After
- [ ] Comparison Chart 3 colonnes
- [ ] Stat Hero Card
- [ ] Manifesto Carousel

Si v{N+1} = 100 % format connu → manque de variété, répétition lasse l'algo Meta.

---

## ☐ 7. Tests prévus

- [ ] Duel A/B défini entre quelles créatives
- [ ] Budget Meta alloué à chaque duel
- [ ] Métriques de succès (CPL, CPM, hook rate, click-through)

---

## ☐ 8. Plan de retour

Si v{N+1} performe moins bien que v{N} sur le test Meta :
- [ ] Plan de rollback
- [ ] Critères d'arrêt (ex : CPL × 1.5 pendant 48 h → kill)

---

## Verdict

```
☐ GO — on build v{N+1}
☐ NO GO — refaire Council / repenser la stratégie
☐ GO partiel — 1-2 angles de v{N+1} seulement, reste en attente
```
