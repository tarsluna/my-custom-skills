# Checklist — Quality Gate (avant de livrer le pack)

> À passer **après** génération des variantes, **avant** sauvegarde dans `projects/clients/{slug}/meta-ads/v1.md`. Si une case échoue → corriger avant de livrer.

---

## A. Format

- [ ] Toutes les variantes au format markdown copy-only (Hook / Body / CTA)
- [ ] Aucune colonne VO/Onscreen
- [ ] Aucun timestamp en colonne
- [ ] Aucun storyboard
- [ ] **≤3 indications scéniques** sur l'ensemble du pack
- [ ] Italique réservé aux indications scéniques
- [ ] Gras réservé aux labels (Hook, Body, CTA, Primary text…)

## B. Hook (les 3 premières secondes)

- [ ] Chaque hook coche ≥3 cases du first-3s checklist
- [ ] Hook spécifique (filtre l'ICP), pas générique
- [ ] Hook ≠ entre les variantes (pas 3 reformulations du même hook)
- [ ] Pas de "Bonjour je m'appelle…", pas de logo intro
- [ ] Pas de jargon avant que le bénéfice soit énoncé
- [ ] Promesse ou tension posée dans la 1ère phrase

## C. Body

- [ ] Phrases courtes (≤15 mots idéalement, ≤20 max)
- [ ] 1 idée par phrase
- [ ] Vocabulaire parlé, pas littéraire
- [ ] Cohérence tu/vous (pas de switch)
- [ ] Lisible à voix haute en 1 souffle
- [ ] ~50% pain / ~50% confidence
- [ ] Mécanisme nommé présent (1× en 30s, 2–3× en 60s+)
- [ ] **Durée minimum 30s respectée** (aucune variante <30s livrée)
- [ ] Bénéfices > fonctionnalités

## D. CTA

- [ ] **1 seule action** par variante
- [ ] **1 bénéfice explicite**
- [ ] **1 raison d'agir maintenant** (urgency / scarcity / because)
- [ ] Friction minimale (action <10s)
- [ ] Cohérent avec le CTA cible défini dans le brief
- [ ] Pas de "Cliquez ici", "N'hésitez pas", "Si vous voulez…"

## E. Angles & variété

- [ ] 3+ angles distincts (pas 3 versions du même)
- [ ] Chaque angle nommé (pain-stat / mechanism / case-result / common enemy / contrarian / identity…)
- [ ] Chaque angle puise dans une case différente du What-Who-When
- [ ] Chaque angle utilise ≥1 pool de confidence
- [ ] Chaque angle utilise ≥1 pool de pain

## F. Specificity & no-go words

- [ ] Chiffres précis (pas "environ", pas "rapidement")
- [ ] Noms réels si dispo (avec accord client)
- [ ] Aucun "incroyable / révolutionnaire / unique au monde" sans proof
- [ ] Aucun "probablement / peut-être / dans certains cas"
- [ ] Aucun "beaucoup de gens / la plupart"
- [ ] Aucun jargon non expliqué dans les 5 premières secondes

## G. Compliance Meta

- [ ] Pas de claims santé interdits
- [ ] Pas de claims finance interdits
- [ ] Pas de before/after corporel
- [ ] Pas d'attribut personnel ("toi qui es divorcé…")
- [ ] Pas de promesses irréalistes non garanties
- [ ] Pas de contenu sensible (alcool, gambling…) sans cadre

## H. Copies Meta texte (par variante)

- [ ] Primary text court ≤125 caractères
- [ ] Primary text moyen 125–200 caractères
- [ ] Primary text long 200–280 caractères
- [ ] Headline ≤40 caractères
- [ ] Description ≤30 caractères
- [ ] Cohérent avec le hook et le CTA de la variante vidéo

## I. Pipeline & contexte

- [ ] Note speed-to-lead présente (OK ou priorité 1)
- [ ] Note congruence LP présente (OK ou action requise)
- [ ] Targeting court inclus
- [ ] Testing plan inclus (variable à tester en 1er = hook)
- [ ] Next steps clairs

---

> ✅ Toutes les cases passent → sauvegarder le livrable.
> ❌ Une case échoue → corriger la variante concernée, ne pas livrer.
