## Direction artistique

### Archetype couleur

Choisir UN archetype principal (cf. `frameworks/03-color-system.md`) :

- [ ] **Urgence / Performance** — rouge/orange sur dark, pour agences, SaaS, promo, FOMO
- [ ] **Confiance / Premium** — bleu/navy sur light, pour consulting B2B, services pro, finance
- [ ] **Energie / Transformation** — orange/jaune sur dark, pour coaching, fitness, formation
- [ ] **Authority / Data** — indigo/bleu tech sur gris, pour finance, tech, analytics

Archetype choisi : _______________

### Ton visuel

Choisir UN ton principal :

- [ ] **UGC brut** — Aspect naturel, peu retouche, face camera, authentique. Couleurs un peu desaturees, texte overlay simple.
- [ ] **Clean corporate** — Fond uni ou photo pro, typo soignee, espaces blancs, minimaliste. Donne confiance.
- [ ] **Bold disruptif** — Gros texte, couleurs contrastees, pattern interrupt. Arrete le scroll. Pas subtil.
- [ ] **Premium epure** — Palette restreinte, typo serif + sans-serif, beaucoup d'espace, luxe accessible.
